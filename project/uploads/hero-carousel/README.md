# Fotos del hero

El carrusel de la portada usa las imágenes de esta carpeta en el orden indicado por el número al inicio del nombre:

```text
01-...   primera imagen
02-...   segunda imagen
03-...   tercera imagen
04-...   cuarta imagen
```

## Reemplazar una foto

Conserva el nombre del archivo y reemplaza la imagen. No es necesario modificar el código.

## Agregar una foto

1. Copia una imagen en esta carpeta.
2. Usa el siguiente número disponible, por ejemplo `05-nueva-foto.jpg`.
3. Agrega esa ruta al arreglo `HERO_PHOTOS` en `project/app/sections.jsx`.

Se recomiendan imágenes horizontales, idealmente en formato `.jpg`, `.png` o `.webp`.
